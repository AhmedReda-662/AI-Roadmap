# Project: AI Learning Roadmap

A self-taught AI learning platform — React + Vite + Tailwind v4 + Redux. Structured
curriculum from programming fundamentals → ML → deep learning → generative AI → AI
engineering. Features: stage/roadmap pages, lesson views (with KaTeX math),
checkpoints/quizzes, projects, interactive math visualizations, search, and progress
tracking.

## Design Context

_Maintained by `/impeccable`. Keep in sync with `.impeccable.md`._

### Users
A **self-taught learner, studying at night** on their own laptop. Dim environment,
finite attention, high stakes (career, identity). The interface must feel like a
trusted, calm mentor — not a hype machine.

### Brand Personality
**Calm · Precise · Expert.** The voice of a careful technical monograph. Low noise,
high trust, generous quiet space. Confidence without shouting.

### Aesthetic Direction
- **Theme:** Both, deliberately designed — default **dark** (warm ink, never pure
  black), with a fully-designed light mode as a peer, not a lazy inversion.
- **Feels like:** a precision instrument / editorial technical journal. Strong type
  hierarchy over dashboard grids.
- **Anti-references:** No purple→blue gradients, no cyan-on-dark glow, no generic SaaS
  dashboard, no emoji-as-icon, no glassmorphism, no repeating icon+heading+text card
  grids.
- **Signature motif:** "the roadmap as an instrument" — a persistent learning spine so
  the learner always knows where they are in the vast field.

### Design Principles
1. **Calm precision** — generous whitespace, restrained accents, content is the object.
2. **The learning spine is sacred** — progress and "where you are" always visible.
3. **Editorial hierarchy** — fewer sizes, more contrast, strong type-led composition.
4. **Warm dusk palette** — tinted neutrals, one disciplined accent, deliberate light mode.
5. **Substance over ornament** — every element communicates or reinforces the instrument.
